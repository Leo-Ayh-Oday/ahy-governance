# Ahy Governance

**Open-source AI Agent Governance. Deploy agents with confidence.**

## Quick Start

```bash
pip install ahy-governance[web]
ahy-dashboard
# Open http://localhost:8081
```

## Features

- **Conflict Detection** — auto-detect and resolve 5 types of agent conflicts
- **Cost Control** — real-time budget visibility + circuit breaker
- **Audit Trail** — SHA-256 hash chain, SOC2/ISO27001 export
- **Self-Healing** — 3-level recovery: rule → LLM → full-auto
- **MCP Tools** — 18 governance tools for Claude Code and any MCP client
- **AGP Discovery** — auto-detect agents across 10 frameworks
